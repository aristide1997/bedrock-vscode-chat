# Screenshots

Captured from the built extension on VS Code, Dark Modern, against a live
Bedrock account in `us-west-2`. Referenced from the
[README](../../README.md#choosing-an-effort-level). Excluded from the packaged
extension by `.vscodeignore`.

| File | Shows |
| --- | --- |
| `01-language-models-variants-off.png` | The model list with `thinking.showEffortVariants` off — one row per model, the shipped default. |
| `02-language-models-variants-on.png` | The same list with it on. Claude 3 Haiku is not expanded (no reasoning mode); the 4.5+ models each gain four rows. `low` and `medium` are hidden here via the eye icons, which is how you curate the list. |
| `03-status-bar.png` | The status bar item reading `Bedrock: think high`. |
| `04-model-picker.png` | The chat model picker. Pinned models sit above; the variants appear under **Other Models** with their effort in both the name and the detail column. |
| `05-effort-quick-pick.png` | The quick pick opened from the status bar: the five levels with their budgets, the current one ticked, and the variants toggle at the bottom. |
